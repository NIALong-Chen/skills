# 简历排版偏好与质量检查

## 已确认的默认版式

- A4、单栏、清晰留白；内容需要时使用两页，不为了凑一页过度缩小字号。
- 姓名与个人信息在照片左侧区域居中，照片位于右上角。优先提取用户原简历中的真实照片，保持比例及透明蒙版，不生成替代人像。没有照片来源时完成其他修改后说明缺少照片。
- 基本信息、联系方式、求职意向、城市和期望薪资分成紧凑的几行，避免碰到照片。
- 电话前加简洁电话图标，邮箱前加信封图标。保留学历与电话之间、电话与邮箱之间的分隔符“｜”。图标不可代替文字，不用花哨彩色emoji。
- 姓名、栏目标题、公司名称、工作内容小标题及教育经历标题均为黑色加粗。正文采用常规字重，保持对比。
- 工作经历标题行依次为公司、职位、起止时间，保持同一水平线，日期右对齐。为长公司名与长职位预留空间；优先调整列宽与间距，不擅自删掉公司名，不把职位和日期放到下一行。
- 同家公司按内容主题归纳，必要时按项目区分；公司工作业绩集中呈现。尽量避免跨页拆开该公司的职责和成果。
- 第二页不重复添加“工作经历（续）”标题。
- 小改动保留已有城市、薪资、照片、图标、成果与布局，不回退已确认的改动。

## 输出检查

1. 对照最新文件及修改清单，检查内容未丢失、数据未重算错误、无过时写作块覆盖。
2. 检查所有标题真实加粗且为黑色；检查电话和邮箱图标、分隔符、照片及同行标题。
3. 检查中文字体嵌入和字形，无方框乱码；正文可搜索复制。
4. 检查两页的边距、换行、分页、页脚，无重叠、裁切、孤立标题。
5. 修改后渲染受影响页面核验；首次导出或整体重排检查每页。发现问题修正后重新检查。

## PDF生成经验

- ReportLab等工具可以绘制电话、信封的简洁矢量图形，避免emoji字体缺字。
- 提取PDF照片时保留soft mask，避免透明区变黑。
- 使用CJK可嵌入字体；CID字体仅有名称可能在缺少字体的环境渲染成方框。
- 从变量字体生成常规和粗体时，使用正确字重实例，并为粗体设置独立的内部字体名称（name表1/2/4/6），防止PDF库把两种字重合并成同一字体。目视检查加粗确实生效。
- 基于字体实际宽度计算图标、文字与分隔符总宽度，再整体居中；不要仅靠固定空格对齐。
